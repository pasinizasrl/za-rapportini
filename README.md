# ZA srl · Rapportini

Pagina per la compilazione dei rapportini giornalieri di cantiere degli operai ZA srl.

- Accesso: nome + PIN a 6 cifre (assegnato dall'ufficio nel gestionale).
- Dati salvati su Supabase tramite funzioni protette: ogni operaio vede e scrive solo i propri rapportini.
- Cantieri dall'elenco comune di Gestione dati; mezzi dall'elenco "Mezzi rapportini".
